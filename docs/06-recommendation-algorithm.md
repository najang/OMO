# OMO · 추천 알고리즘 설계 (규칙 기반 v1)

## 옷차림 레벨 (기온 구간별)

| Level | 기온 구간 (°C) | 예시 옷차림 |
|-------|---------------|-------------|
| 1 | 28 이상 | 민소매, 반팔, 반바지 |
| 2 | 23 ~ 27 | 반팔, 얇은 셔츠 |
| 3 | 20 ~ 22 | 얇은 가디건, 긴팔 |
| 4 | 17 ~ 19 | 맨투맨, 가디건 |

## 개인화 보정 로직

```
adjusted_temp = feels_like + user_temp_profile.temp_offset
level = level_table.lookup(adjusted_temp)
```

## 피드백 → offset 업데이트

| 피드백 | offset 변화량 | 의미 |
|--------|--------------|------|
| HOT | +0.3°C | "추천보다 더 덥게 입었다" → 다음엔 가볍게 |
| MODERATE | 0 | 변화 없음 |
| COLD | -0.3°C | "추천보다 더 춥게 입었다" → 다음엔 두껍게 |
| INDOOR | 무시 | 데이터 오염 방지 |

**보정 제약**
- offset 범위: `-3.0 ~ +3.0` (clamp)
- 초기 N=5 피드백 누적까진 보정 계수 0.5배 (성급한 학습 방지)
