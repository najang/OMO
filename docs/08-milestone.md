# OMO · 마일스톤 & 향후 검토

## 마일스톤

### Phase 1 — MVP (4~6주)
- 회원가입, 알림 설정
- 날씨 조회 + 규칙 기반 추천
- 푸시 알림 스케줄러
- 피드백 토스트 + 기록

### Phase 2 — 개인화 (2~3주)
- 마이페이지 일자별 기록
- 피드백 기반 temp_offset 보정 로직

### Phase 3 — 고도화 (지속)
- 옷차림 직접 기록
- 통계/인사이트 리포트
- 알림 메시지 개인화

## 향후 검토 사항

| 항목 | 내용 |
|------|------|
| 위치 권한 처리 | 위치 자동 갱신 vs 유저 설정 고정 위치 → 우선 후자로 단순화 |
| 다중 알림 | 하루 1회 알림으로 시작, 추후 출/퇴근 2회 등 확장 |
| 추천 모델 고도화 | 데이터 충분히 쌓이면 사용자 클러스터링 → 협업 필터링 도입 검토 |
| 이벤트 발행 | 피드백 등록 시 `FeedbackCreatedEvent` 발행 → temp_offset 갱신을 별도 이벤트 핸들러로 분리 |
